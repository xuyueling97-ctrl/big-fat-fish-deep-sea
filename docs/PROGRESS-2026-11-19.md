## 环境备忘

- PowerShell 控制台按 GBK 解码中文，`node` 直接打印中文 JSON 会乱码 → 报告一律重定向到文件再用 `read_file` 读
- `git push` 的进度走 stderr，PowerShell 会报 `NativeCommandError` 且 `$LASTEXITCODE` 可能为 1，**这是假警报**；以输出里的 `<sha>..<sha>  main -> main` 为准
- PowerShell 不支持 heredoc（`<<'MSG'`），多行提交信息要写成临时文件再 `git commit -F`
- 项目根目录改名会因 `codely.exe` 占用 cwd 而失败
- Edge 路径写死：`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
